- `site/carnet-mcu.html` — le traqueur de visionnage MCU final ("Carnet MCU") : parcours (nouveau/Doomsday/rewatch), filtres, progression, sauvegardée en `localStorage`.

- `site/lignes-du-multivers.html` — frise chronologique SVG des continuités (Earth-616, X-Men, Sony, Netflix…) ("Lignes du Multivers").

Chaque fichier est autonome (HTML + CSS + JS inline, sans dépendance externe) : ouvrez-le simplement dans un navigateur.
